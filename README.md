# MATGame

Welcome to MATGame! This is a fun and engaging game designed to challenge your mathematical skills and provide hours of entertainment.

## Features

- Multiple levels with increasing difficulty
- Special numbers and brick positions to add variety to the gameplay
- Smooth animations and intuitive controls
- Beautiful graphics and engaging sound effects

## How to Play

1. **Objective:** Reach the target score by performing mathematical operations on the grid cells.
2. **Controls:** Tap on the grid cells to select and perform operations.
3. **Special Numbers:** Watch out for special numbers that can change the gameplay dynamics.
4. **Bricks:** Some cells are bricks and cannot be moved.
